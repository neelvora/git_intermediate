# git_intermediate

My copy of the exercise files for the LinkedIn Learning course Git Intermediate Techniques. None of the content is mine: every commit in every branch is by the course authors, and I did not change any of the files.

`demo_repo/` holds two plain text lists, a shopping list and a to-do list, which the exercises edit. The branches are the states the course walks through. `key_feature` adds a file and edits the shopping list, `old_topic` adds a line to the to-do list, and `main` is the starting point.
